# GoPro / Garmin Edge Remote — KiCad Project

## State of this project
- **Schematic** (`gopro_garmin_remote.kicad_sch`): complete and **validated**.
  Generated programmatically then verified with `kicad-cli` (load OK, netlist
  export OK). All expected nets are correctly formed: `VBAT`, `GND`,
  `SWDIO`, `SWCLK`, `GPIO_CAM_ON`, `GPIO_CAM_OFF`, `GPIO_PAGE_R`, `GPIO_PAGE_L`,

  the extended-pad template (hand soldering) seen previously, referenced by U1.

## ⚠️ Out of sync: thermistor removed from the design
`NTC1`, `R1`, and the `NTC_SENSE` net below are from an earlier design
that used an external NTC thermistor for temperature. That was replaced
by the nRF52832's internal die temperature sensor (no external component)
— see `doc/gopro_garmin_remote_specs.md`, "Internal temperature sensor".
This schematic has **not been updated yet** to remove them — treat the
table below as describing the *previous* design for that part, and remove
`NTC1`/`R1`/`NTC_SENSE` during the next schematic edit.

## ⚠️ Points to check before fabrication

1. **Actual E73 pinout**: the `U1` symbol uses **placeholder pin numbers**
   (1–7, 10–15) that do NOT necessarily match the module's real physical pins
   (43 castellated pads). Before routing a PCB, re-align these numbers with
   the real pinout table from the Ebyte datasheet, or with
   [spbnick's kicad-lib](https://github.com/spbnick/kicad-lib) already
   verified against real fabrication.
2. **E73 footprint**: the footprint provided is an **educational template**
   (extended-pad technique demonstrated on 8 pins). It needs to be completed
   for the 43 real pins before routing the PCB.
3. **Schematic layout**: the labels are a bit visually cramped (generated by
   script, not by a human in the editor). The electrical connectivity is
   correct, but you'll likely want to rearrange the labels in KiCad for
   readability (Tools > nothing to recompute, just visual comfort).

## Suggested next steps

1. Remove `NTC1`, `R1`, and the `NTC_SENSE` net (superseded by the
   internal temperature sensor — see above).
2. Open `gopro_garmin_remote.kicad_pro` in KiCad 7+, review the schematic on
   screen, rearrange if needed.
3. Complete the real E73 pinout (symbol + footprint).
4. Switch to PCB mode (`Tools > Update PCB from Schematic`), place the
   components, route the traces.
5. Add the enclosure outline / mounting holes based on the chosen handlebar
   mount.

## Tools used to generate this project
- `kiutils` (Python) to write a syntactically valid `.kicad_sch`.
- `kicad-cli` 7.0.11 to validate loading and export the netlist/PDF.
- Symbols reused as-is from the standard KiCad libraries:
  `Device:R`, `Device:C`, `Device:Battery_Cell`, `Device:Thermistor_NTC`,
  `Switch:SW_Push`, `Connector_Generic:Conn_01x04`.
